# 새로운 문서는 어떻게 제출하나요?

1. 상단의 "Issues" 탭을 클릭한 후, "New Issue"를 선택하세요.

2. 제목(Title)란에 문서에 사용할 짧은 영어 이름을 입력하세요(예: `ender-dragon`; 영문자, 숫자, 하이픈만 사용 가능).

3. 본문(Body)란에 마크다운(Markdown) 형식의 내용을 직접 붙여넣으세요(표준 마크다운 문법을 모두 지원합니다).

제출해 주시면 해당 내용을 `ender-dragon.md` 파일로 저장하고 배포하여, `?ender-dragon`을 통해 접근할 수 있도록 설정해 드립니다.

참고: 저장소를 깔끔하게 유지하기 위해 문서 내에 `<script>` 태그는 포함하지 말아 주세요(기술적으로는 실행될 수 있더라도, 발견 시 삭제할 예정입니다). 텍스트, 이미지, 표 위주로 작성하시는 것을 권장합니다.

# 개인 설정
목차 제목 옆에 있는 해와 달 모양 버튼을 클릭하여 어두운 모드와 밝은 모드를 전환하거나, 길게 눌러 배경 화면을 업로드할 수 있습니다.

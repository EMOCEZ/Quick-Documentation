# How do I submit a new document?

1. Click the "Issues" tab at the top, then click "New Issue."

2. In the title field, enter the short English name you would like to use for the document (e.g., `ender-dragon`; use only letters, numbers, and hyphens).

3. Paste your Markdown content directly into the body field (all standard Markdown syntax is supported).

Once submitted, I will save it as `ender-dragon.md` and deploy it, making it accessible via `?ender-dragon`.

Note: To keep the repository clean, please do not include `<script>` tags in your documents (while they might technically run, I will remove them). Sticking to text, images, and tables is the best approach.

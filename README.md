# How to Submit New Documentation?

1. Click the "Issues" tab at the top of the page, then click "New Issue."

2. In the title field, enter a short English name for your document (e.g., `ender-dragon`; use only letters, numbers, and hyphens).

3. Paste your Markdown content directly into the body section (all standard Markdown syntax is supported).

Once submitted, I will save it as `ender-dragon.md` and deploy it; you will then be able to access the document via `?ender-dragon`.

Note: To keep the repository clean, please do not include `<script>` tags in your documentation (while they might technically work, I will remove them). It is recommended to use only text, images, and tables. # Personalization
You can toggle between dark and light modes by clicking the sun/moon icon next to the table of contents heading, or long-press to upload a custom background.

# ¿Cómo puedo enviar un documento nuevo?

1. Haz clic en la pestaña "Issues" (problemas) en la parte superior y, luego, en "New Issue" (nuevo problema).

2. En el campo del título, introduce el nombre corto en inglés que quieras usar para el documento (por ejemplo, `ender-dragon`; utiliza solo letras, números y guiones).

3. Pega tu contenido en formato Markdown directamente en el cuerpo del mensaje (se admite toda la sintaxis estándar de Markdown).

Una vez enviado, lo guardaré como `ender-dragon.md` y lo publicaré, haciéndolo accesible a través de `?ender-dragon`.

Nota: Para mantener el repositorio ordenado, por favor no incluyas etiquetas `<script>` en tus documentos (aunque técnicamente podrían ejecutarse, las eliminaré). Lo ideal es limitarse a texto, imágenes y tablas.

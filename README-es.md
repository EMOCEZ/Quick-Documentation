# ¿Cómo reportar un nuevo problema?

1. Haz clic en la pestaña "Problemas" en la parte superior de la página y luego en "Nuevo problema".

2. En la barra de título, introduce un nombre corto en inglés para este documento (por ejemplo, `ender-dragon`; solo se permiten letras, números y guiones).

3. Pega tu contenido Markdown directamente en el cuerpo del documento (se admite toda la sintaxis Markdown estándar).

Tras la entrega, lo guardaré como `ender-dragon.md` y lo implementaré. Podrás acceder al documento mediante `?ender-dragon`.

Nota: Para mantener el repositorio limpio, no incluyas etiquetas `<script>` en el documento (aunque técnicamente funcione, las eliminaré). Se recomienda usar solo texto, imágenes y tablas.

# Personalización

Puedes hacer clic en los botones del sol y la luna junto a los títulos de los directorios para alternar entre el modo oscuro y el claro, o mantener pulsado para subir un fondo.
